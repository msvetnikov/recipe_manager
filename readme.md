# Recipe Manager (v3.0 - Pure OOP)

Консольный менеджер рецептов на Python, позволяющий создавать, хранить и фильтровать рецепты в формате JSON. В этой версии проект полностью переведен на объектно-ориентированные рельсы (ООП): все глобальные переменные и свободные функции были заменены классами.

## 📌 Особенности этой версии
* **Чистый ООП-стиль**: Из кода полностью удалены глобальные списки и изолированные функции. Вся логика инкапсулирована внутри классов.
* **Класс-менеджер `RecipeBook`**: Управляет всей коллекцией рецептов и взаимодействует с файлом JSON через методы класса (`@classmethod`).
* **Магические методы (`Dunder methods`)**: 
  * `__str__` и `__repr__` для удобного и понятного вывода рецептов в консоль.
  * `__eq__` и `__hash__` для возможности корректного сравнения объектов рецептов между собой.
* **Валидация данных**: Проверка на пустые строки в названии и корректность времени приготовления.

## 🛠️ Архитектура проекта

### Класс `Recipe`
Инкапсулирует в себе свойства отдельного рецепта:
* `id`, `title`, `instructions`, `time`, `ingredients`.

### Класс `RecipeBook`
Отвечает за управление базой данных рецептов:
* `_recipes_storage` — приватный список для хранения объектов рецептов.
* `load_recipes()` — загружает базу данных и превращает словари из JSON в объекты класса `Recipe`.
* `create_recipe(recipe: Recipe)` — валидирует объект рецепта, присваивает ему ID, добавляет в хранилище и сохраняет в JSON.
* `get_recipe_by_id(target_id)` — ищет рецепт по ID (или выбрасывает ошибку `RecipeNotFoundError`).
* `filter_by_time(max_time)` — возвращает список подходящих объектов рецептов.

## 🚀 Как запустить и использовать

1. **Системные требования**: Убедитесь, что у вас установлен **Python 3.10+** (используется новый синтаксис `dict | None`). Дополнительные библиотеки не требуются.
2. Сохраните код в файл `main.py`.
3. Использование в коде выглядит так:

```python
# Загрузка базы (обязательно при старте)
RecipeBook.load_recipes()

# Создание и сохранение рецепта
new_recipe = Recipe("Омлет", "Взбить и пожарить", 5, {"Яйца": "2 шт"})
RecipeBook.create_recipe(new_recipe)

# Поиск и фильтрация
recipe = RecipeBook.get_recipe_by_id(1)
fast_recipes = RecipeBook.filter_by_time(15)
