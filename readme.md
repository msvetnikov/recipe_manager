# Recipe Manager (v2.0 - OOP Transition)

Консольный менеджер рецептов на Python, позволяющий создавать, хранить и фильтровать рецепты в формате JSON. В этой версии произошел переход от процедурного подхода к объектно-ориентированному (ООП).

## 📌 Особенности этой версии
* **Использование ООП**: Введена сущность `Recipe` (класс), которая отвечает за структуру отдельного рецепта и его внутреннее представление.
* **Магические методы (`Dunder methods`)**: 
  * `__str__` и `__repr__` для удобного и понятного вывода рецептов в консоль.
  * `__eq__` и `__hash__` для возможности корректного сравнения объектов рецептов между собой.
* **Валидация данных**: Проверка на пустые строки в названии (строковые методы `.strip()`) и корректность времени приготовления.
* **Сохранение состояния**: Автоматическая десериализация JSON-файла в объекты Python при запуске и serialization объектов обратно в JSON (`__dict__`) при сохранении.

## 🛠️ Архитектура проекта

### Класс `Recipe`
Инкапсулирует в себе все свойства рецепта:
* `id` (автоматически генерируется при сохранении)
* `title` (название)
* `instructions` (инструкция)
* `time` (время приготовления в минутах)
* `ingredients` (словарь с ингредиентами)

### Основные функции управления:
* `load_recipes()` — загружает базу данных и превращает сырые словари из JSON в полноценные объекты класса `Recipe`.
* `create_recipe(recipe: Recipe)` — принимает объект рецепта, валидирует его, присваивает ID и сохраняет в `recipes.json`.
* `get_recipe_by_id(target_id)` — ищет рецепт по ID (возвращает объект или выбрасывает ошибку `RecipeNotFoundError`).
* `filter_by_time(max_time)` — возвращает список подходящих объектов рецептов.
