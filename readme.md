# Recipe Manager (v4.0 - Advanced OOP & CRUD)

Консольный менеджер рецептов на Python, поддерживающий работу с обычными и видео-рецептами. В этой версии архитектура проекта вышла на продвинутый уровень ООП: реализовано наследование, примеси (Mixins), инкапсуляция через геттеры/сеттеры и полноценный CRUD-функционал для управления базой данных JSON.

## 📌 Особенности этой версии
* **Поддержка видео-рецептов**: Через наследование добавлен класс `VideoRecipe`, расширяющий базовую модель ссылками на видеоматериалы.
* **Использование Миксинов (`Mixins`)**: Класс `JsonSerializableMixin` автоматически превращает любые свойства объектов (даже приватные) в плоские словари для безболезненного сохранения в JSON.
* **Контроль доступа и Валидация**: Защита ID от перезаписи с помощью `@property` и жесткая валидация времени через `@time.setter`.
* **Полноценный CRUD**: Класс-менеджер теперь умеет не только создавать и читать, но также обновлять (`update_recipe`) и удалять (`delete_recipe`) данные с автоматической синхронизацией файла.
* **Истинный Полиморфизм**: Метод `print_all_recipes()` автоматически вызывает нужный `__str__` в зависимости от типа рецепта (обычный или видео).

## 🛠️ Архитектура проекта

### Компоненты и Классы:
* `JsonSerializableMixin` — вспомогательный класс-примесь для сериализации объектов в `dict` и `json`.
* `Recipe` — базовый класс рецепта с инкапсулированными свойствами `_id` и `_time`.
* `VideoRecipe` — дочерний класс, включающий дополнительное поле `video_url`.
* `RecipeBook` — центральный менеджер базы данных с приватным списком `_recipes_storage`.

### Операции CRUD в `RecipeBook`:
* **Create**: `create_recipe(recipe)` — валидация, расчет ID и сохранение.
* **Read**: `get_recipe_by_id(id)`, `filter_by_time(time)`, `print_all_recipes()`.
* **Update**: `update_recipe(id, new_title, new_time)` — безопасное обновление полей.
* **Delete**: `delete_recipe(id)` — удаление объекта из памяти и файла.

## 🚀 Как запустить и использовать

1. **Системные требования**: Убедитесь, что у вас установлен **Python 3.10+** (используется синтаксис `dict | None`). Дополнительные библиотеки не требуются.
2. Сохраните код в файл `main.py`.
3. Использование нового функционала в коде:

```python
# Загрузка базы (обязательно при старте)
RecipeBook.load_recipes()

# 1. Создание обычного и видео-рецепта
pasta = Recipe("Паста", "Сварить макароны", 15, {"Макароны": "200г"})
scrambled_eggs = VideoRecipe("Яичница", "Пожарить", 5, "[https://youtube.com/](https://youtube.com/)...", {"Яйца": "3 шт"})

RecipeBook.create_recipe(pasta)
RecipeBook.create_recipe(scrambled_eggs)

# 2. Обновление рецепта (включится сеттер валидации)
RecipeBook.update_recipe(target_id=1, new_title="Итальянская паста", new_time=12)

# 3. Вывод всех рецептов (сработает полиморфизм)
RecipeBook.print_all_recipes()

# 4. Удаление рецепта
RecipeBook.delete_recipe(target_id=1)
