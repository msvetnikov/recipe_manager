# Recipe Manager (v1.0 - Functional Style)

Простой консольный менеджер рецептов на Python, позволяющий создавать, хранить и фильтровать рецепты в формате JSON. Это первая, базовая версия проекта, реализованная с использованием функций и процедурного (функционального) подхода.

## 📌 Особенности этой версии
* **Процедурный/Функциональный стиль**: Вся логика работы с данными вынесена в отдельные функции, а состояние хранится в глобальном списке.
* **Работа с файлами**: Автоматическое чтение и запись базы рецептов в файл `recipes.json`.
* **Валидация данных**: Кастомные исключения (`InvalidRecipeError`, `InvalidCookingTimeError`) для обработки некорректного времени приготовления или отсутствия названия.
* **Фильтрация**: Возможность поиска рецептов по ID или по ограничению времени готовки.

## 🛠️ Структура данных

В этой версии рецепт представляет собой обычный словарь (`dict`), а база данных — список таких словарей (`list[dict]`).

**Пример структуры рецепта:**
```json
{
    "id": 1,
    "title": "Ночная овсянка",
    "ingredients": {"Овсянка": 70, "Творожок": 100, "Молоко": 100},
    "instructions": "Тут инструкция",
    "time": 5
}

```

### Основные функции:

* `create_recipe(recipe)` — валидирует данные, присваивает уникальный ID, добавляет рецепт в список и сохраняет в JSON.
* `get_recipe_by_id(target_id)` — ищет рецепт по его идентификатору. Возвращает ошибку `RecipeNotFoundError`, если ID не найден.
* `filter_by_time(max_time)` — возвращает список рецептов, время приготовления которых меньше или равно `max_time`.

## 🚀 Как запустить

1. Убедитесь, что у вас установлен Python 3.x.
2. Сохраните код в файл (например, `main.py`).
3. Запустите скрипт через терминал:
```bash
python main.py

```
